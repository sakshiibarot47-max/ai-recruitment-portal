# AI Recruitment Portal (HireAI)

AI-powered recruitment and hiring portal where job seekers apply with resumes, and recruiters view candidates ranked by match score. Built with React, Node.js/Express, and SQLite.

## Tech Stack
* **Frontend:** React, Vite
* **Backend:** Node.js, Express.js
* **Database:** SQLite (`better-sqlite3`)
